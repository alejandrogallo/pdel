# pdksynth pdel ports

Namespace: `@pdel/pdksynth/...`.

These definitions correspond one-to-one to top-level abstractions from Derek Kwan's `pdksynth` repository. The upstream project is GPL-3.0. Source: https://github.com/derekxkwan/pdksynth

The ports preserve the upstream abstraction names and intended sound/function. Where upstream depended on pdkm/pdkvabs/zexy, this tree uses local Pd-Vanilla/pdel building blocks where practical.

Important: these are hand-translated/reconstructed pdel ports from the upstream abstraction inventory and documented intent, not automatically generated byte-for-byte decompilations. Keep the upstream source as the reference when exact parameter/interface compatibility matters.
